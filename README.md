## 先说结论

**没有一种方法可以保证中国大陆所有地区、设备、运营商、时段、海外服务都稳定可用。** 能持续工作的系统依赖可验证的连接质量、适当合规路径、备份与回滚能力。选择方法要先匹配目标、设备和安全边界。

中国大陆对跨境联网、国际专线及相关经营活动存在监管要求。此项目用于帮助读者理解技术与风险、开展获得授权的网络管理；**不提供节点、订阅账号、盗版软件、跨境网络经营服务或“合法性保证”**。企业跨境传输、商业经营和敏感数据请按适用规定审核。阅读 [法规与边界](docs/00-阅读前先看.md) 与 [企业接入](docs/18-企业接入与合规边界.md)。

## 12 种技术路线：按用途和责任分类

| 类别 | 包含 | 实际风险重点 |
|---|---|---|
| 企业合规接入 | 专线、SD-WAN、SASE/ZTNA | 法规/合同、数据流、SLA |
| 商业接入 | 商业 VPN App、代理订阅（机场） | 信任第三方、配置泄漏、服务持续性 |
| 自建服务器 | Outline/SS、AmneziaWG、Xray/REALITY、Hysteria 2/TUIC | 运维、协议兼容、服务器安全、线路失效 |
| 标准 VPN/私有组网 | WireGuard、OpenVPN、IKEv2、Tailscale、ZeroTier | 仅能解决授权场景、不能保证穿透限制 |
| 移动网络 | 境外 SIM/eSIM/数据漫游 | 机型、漫游出口、套餐与实际可用性 |
| 远端使用 | 海外云电脑/远程桌面、Tor 网桥浏览 | 不覆盖全部本机 APP、隐私和访问限制 |

**选择时请看五层：目标应用 → 接入网络 → 协议 → 真实出口 → 客户端路由。** 客户端本身不会凭空提供服务；看见国外 IP 也不等于符合某平台的国家资格。

### 按场景选择「使用配置」

- **低频上网**：按需开启，最少权限，故障时恢复普通网络。
- **网页+开发工具**：逐个验证浏览器、CLI、IDE、Docker；先解决目标应用再扩大路由范围。
- **手机/iPad 移动办公**：Wi-Fi、蜂窝、设备切换和热点分开验收。
- **重要业务操作**：登录、支付、客户资料与公开资料分层；账号异常时优先官方恢复。
- **连续生产**：独立上游+独立接入介质+离线缓冲，故障时先恢复业务再分析。
- **企业生产与敏感数据**：仅通过公司授权、受管理、可审计的网络路径，不以私人接入替代。
