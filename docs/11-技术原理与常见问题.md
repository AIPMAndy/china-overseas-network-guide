# 11｜技术原理：用大白话解释为什么会出问题

## 1. 为什么同一个软件，有些人能用、有些人不行？

你的网络请求大致经过：**设备 → 客户端及系统路由 → 家宽/移动运营商 → 服务端所在网络 → 目标站点**。其中任意一段拥堵、不可达、受策略限制、认证失败，都可能造成问题。客户端名字相同，不等于线路、服务、密钥和本地 DNS 相同。

## 2. 什么是代理、VPN、隧道、节点和机场？

- **代理**：中间转发请求的应用层或网络层机制。HTTP 代理、SOCKS 代理各有应用支持和覆盖边界。
- **VPN**：通过虚拟网络接口等方式建立受控制的逻辑网络连接；具体的路由与加密取决于实现。
- **隧道**：把某种网络流量封装进另一种连接传输的技术统称，不等于天然匿名。
- **节点**：行业口语里常指一个服务端入口；它是否由可信实体运营、有没有日志，无法仅从名称得知。
- **机场**：中文互联网中对一些订阅服务商的俗称；资质、隐私和安全差异很大，不能把它等同于正规批准的跨境接入服务。

## 3. DNS 是什么？为什么会出现“能打开 IP，打不开域名”？

DNS 把域名变成 IP，就像查地址簿。但“直接打开 IP”对 HTTPS 网站不一定正常，因为 TLS 证书校验、SNI、虚拟主机仍需要域名。排障应分开验证 DNS 解析、TCP/TLS、HTTP 响应，不把其中之一当成全部。

## 4. 为什么系统代理有效，终端却不能用？

很多图形 App 读取系统代理；终端程序、容器或后台服务可能分别读取自己的代理环境变量或配置。TUN 可以覆盖更多流量，但也可能改变 DNS、IPv6 和局域网路由。

## 5. 为什么 IP 属地和设备位置不是一回事？

网站可能综合 IP 位置库、账号历史、GPS/定位权限、浏览器指纹、支付地区和安全风控来判断地区。一个国外出口并不能代表你的设备、身份或帐号真的位于那个国家。不要用伪造身份绕过平台的服务条款。

## 6. 是不是买住宅 IP 就一定稳定/一定不会封？

不是。稳定性受网络路由、供应商和负载影响；账号的使用资格和风控并非只看 IP。宣称“住宅 IP = 100% 安全”的营销没有足够依据。

## 7. 为什么不能到处贴订阅链接让别人排障？

不少订阅链接、二维码和配置文件直接包含访问凭据。泄露之后他人可能占用额度、查看部分连接信息，或增加相关服务的滥用风险。排障仅分享**脱敏**版本与错误类别。

## 8. 断网如何恢复？

先关闭隧道/客户端，再确认系统代理与 VPN 配置，必要时重新连接原来的 Wi‑Fi；企业设备请使用 IT 官方恢复流程。切记要先保存原设置，无法恢复时找设备管理员。

## 9. “连接成功”是不是代表所有 App 都安全？

不是。不同 App 的代理、DNS 与路由覆盖可能不同；网站仍可能通过账号和设备信息识别你。需要端到端加密、软件权限管理、MFA 和最小权限。

## 10. 这个项目多久更新一次？

工具发布频繁。本仓库记录每次核对日期，并把**官方文档/发行页**作为事实来源。某个截图或按钮名发生变化，请提交 Issue 并附上**不含个人信息**的变化描述。
