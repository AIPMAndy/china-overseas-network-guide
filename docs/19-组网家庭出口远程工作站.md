# 19｜Tailscale、WireGuard、ZeroTier、海外家庭出口与云工作站

**本章结果：**知道“组网”与“所有互联网流量经境外出口”之间的差别，并能在被授权的自有设备上做出口节点实验。

## 概念分层

- **私有组网**：连接自己的手机、Mac、NAS、服务器，使设备彼此可达；默认不一定改变公网出口。
- **Exit Node / 出口节点**：指定某台被允许的设备转发外网请求；它离线或缺少权限就会失败。
- **远程桌面**：人在本地操作远端计算机。本地程序仍在本地网络运行。

## Tailscale 出口节点：官方操作路径

1. 确认两台设备**均属于你或已获授权**，并安装 [Tailscale 官方客户端](https://tailscale.com/download)。
2. 在境外且有联网许可的设备上登录同一受控 tailnet，按照官方 [Exit Node 文档](https://tailscale.com/docs/features/exit-nodes) 广告它可以作为出口节点。
3. 由管理员在管理控制台批准节点及使用权限（自定义 ACL 时注意 `autogroup:internet`）。
4. 在客户端显式选择该出口节点；如果需要本地打印机/NAS，检查“允许访问局域网”。
5. 访问你有权访问的测试网站，检查公网出口是否符合预期；再测试断开与退出后的网络恢复。
6. 记录海外设备开机、电源、密钥到期、出口 IP、运营商和备份设备。**不要把它描述成“中国网络必通”**。

官方强调：默认 Tailscale 仅承担组网；使用 Exit Node 需要设备、管理员、客户端分别启用。任何一环缺失时，不能宣称全局出口已生效。

## 原生 WireGuard / OpenVPN / IKEv2

这些标准 VPN 适合**允许的远程接入/内网组网**，在受限制网络上是否可达取决于传输特征和网络条件；仅因其“加密强”不能推断抗阻断能力强。先做合法用途、目标端口、路由、MTU、DNS、权限和密钥轮换的验收。

## 海外住宅宽带出口需要额外谨慎

- “住宅 IP”并不天然可靠：家庭设备可能离线、动态 IP 变更、上行带宽低、电力中断。
- 禁止利用未经他人知情同意的设备作为中继；不要向陌生人购买所谓“他人住宅出口”访问权。
- 家人共用出口时，明确访问控制与日志保留边界，避免设备横向访问。
