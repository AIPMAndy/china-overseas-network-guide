# 18｜企业跨境办公：专线、SD-WAN、SASE 与远程桌面

**本章结果：**能写出一份可供公司 IT / 法务 / 采购评审的跨境接入需求，不把个人 VPS 当成企业跨境专线使用。

## 企业网络选型从“业务对象”开始

| 业务需求 | 优先探索 | 核查点 |
|---|---|---|
| 企业员工访问海外内部系统 | 经审批的企业远程访问 / ZTNA / SASE | 终端身份、MFA、最小权限、审计 |
| 海外分支和大陆办公点通信 | 持资质服务方提供的合规专线 / SD-WAN | 电信服务资格、合同业务用途、SLA、数据流向 |
| 外贸、跨境会议、远程协作 | 经公司核准的应用与接入方案 | 会议音视频 QoS、地点/设备限制、故障响应 |
| 研发 API、生产服务互联 | 云厂商合规解决方案、区域化部署 | 数据跨境、日志、访问控制、云服务条款 |
| 单一海外工作软件 | 受管远程桌面 / VDI / Cloud PC | 远端输入、文件传输、端点身份、成本 |

**法规原始来源**：[工信部 2017 年《关于清理规范互联网网络接入服务市场的通知》](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2017/art_a940645e940946e1a62cd6c90a4e994e.html) 对未经批准开展跨境经营活动、国际专线用途等作了要求。此处不将监管文件一句话推导为全部个人或企业场景的法律结论，涉及经营或客户数据须由专业人员核查。

## 采购前 10 个问题

1. 谁是签约主体？由哪家电信运营商提供跨境资源？能否提供可核查资质？
2. SLA 定义是什么：可用率、修复时限、赔付、排除条款？
3. 业务流量实际经哪些国家/区域？哪些系统可能处理账号、日志和客户数据？
4. 是否有身份认证、设备管理、最小权限、访问审计和应急断开？
5. 员工离职、设备丢失后，权限如何撤销？多长时间生效？
6. 如果线路断开，企业系统是否存在业务连续性预案？
7. 支持哪些操作系统、视频会议、SSH/CI/CD、内网域名和 MDM？
8. 税费、带宽、跨区流量、超额、一次性部署及提前解约费用是什么？
9. 政策变更、服务区域变更谁通知、谁承担迁移？
10. 发生网络安全事故时如何联动？有没有日志保留和通报规则？

## 远程桌面并非透明 VPN

远程桌面（如部署在公司许可环境中的 VDI 或远端云电脑）是**把应用运行在远端，设备传输键鼠/画面**。它不自动让本地 App、Mac 提词器、iPhone 客户端走海外出口。还要审计剪贴板、文件传输、远端摄像头、支付和账号登录位置。

**交付物**：填写 [企业跨境接入需求表](../templates/企业跨境接入需求表.md)，未经审批不直接部署在生产机。
