# 30｜怎么买最划算：试用、供应商风险、成本模型与退出策略

本项目不提供“机场排名”“最稳服务商排行”或长期可用保证；原因是缺少能覆盖地区、运营商和时段的可复核跨供应商数据。**采购目标是符合规则的真实业务可用性 + 可退出成本，而不是最低价格。**

## 1. 采购前问自己 8 个问题

1. 我到底需要哪个真实任务？文档访问、上传、会议、API，还是企业内网？
2. 我的设备和系统是什么？需要多少人、多少同时连接、有没有公司 MDM？
3. 订阅/账号/设备配置由谁保管？丢失后能否恢复和吊销？
4. 有哪些隐私承诺？是否有独立审计？日志保留、投诉和数据出口怎么说明？
5. 取消和退款条款是什么？能否拿到官方票据？
6. 支付后是否要安装陌生证书、远程控制软件、关闭杀毒或提交大量隐私？**若是，先停止采购。**
7. 公司用途是否合法合规、符合客户协议？
8. 我是否已经拥有有效的独立备用？

## 2. 采购 3 段式：先最小，再验证，再付长周期

**阶段 1：桌面研究**：验证服务商公司主体、官网、隐私条款、更新时间、软件发布方、工单渠道、退款政策。供应商宣传不能代替测量。

**阶段 2：小额试用**：在两种网络、三种常用时段，完成 3 个真实任务并记录成败、p95、异常。若免费试用无法在你的运营商使用，不因“别人说很稳”购买年费。

**阶段 3：按需扩容**：确认体验、账单、权限与退出方式后，才考虑季度/年付。个人场景可先采用月付降低供应商倒闭或线路变更损失；企业看 SLA、退出条款和数据销毁。

## 3. 从 TCO 看成本

**月均总拥有成本（TCO） = 订阅/服务器费用 + 域名/软件费用 + 运维时间 × 时间价值 + 故障期望损失 + 备份费用。**

以下全部是**演示假设，不是市场报价**：

| 项目 | 低价方案 A | 稳定方案 B |
|---|---:|---:|
| 月订阅/服务器 | ¥30 | ¥100 |
| 每月维护工时 | 3h | 0.5h |
| 假设每小时机会成本 | ¥100 | ¥100 |
| 每月故障预计影响 | ¥150 | ¥50 |
| 独立备用网络成本 | ¥40 | ¥40 |
| **计算后的 TCO** | **¥520** | **¥240** |

在这些假设下，看似贵的 B 总成本反而低。但真实选择必须用你的账单和停工数据填写 [月度成本核算表](../templates/月度成本核算表.csv)，不能把示例理解成“某品牌更稳定”。

## 4. 评分模型（建议个人默认权重，可调整）

| 维度 | 参考权重 | 如何评分（1—5） |
|---|---:|---|
| 实际任务成功率 | 30% | 按自己的 7 天测量记录 |
| 失效后的恢复能力 | 20% | 真实备用演练，非商家承诺 |
| 透明度与账户安全 | 20% | 官网、隐私声明、MFA、可吊销能力 |
| 客户端适配与运维成本 | 15% | 能否在所有必须设备执行任务 |
| 价格与退出成本 | 10% | TCO、退款和续费限制 |
| 合规/企业要求 | **一票否决** | 业务不符政策则不采购 |
| 其他增值体验 | 5% | 售后、工单响应等 |

不要把测不到的维度赋 5 分；写 `未知`，保留决策不确定性。

## 5. 识别推广内容

X、YouTube、论坛、Telegram、评测站的优惠码和测速截图只能做线索；重复发布、返佣、失去上下文的测速都应降级为营销素材。需要记录**发布和测试的确切日期、地点范围、设备、运营商、时段、样本数**，不得凭“原生/住宅/独享”几个标签判断安全或地区资格。

## 6. 退出机制

- 保存合法采购合同、取消入口、已付金额、续费日和联系人。
- 停用后在服务商面板吊销访问密钥，移除旧设备授权和客户端残留系统代理。
- 如果涉及公司数据，核查数据留存与销毁承诺，并按组织流程完成交接。
- 到期前 7 天评估是否续约；任何大版本升级前先保留可回滚的已知配置。
