# 28｜主备策略工程化：一条线路失效，工作继续

**本章目标：**把“我买了两条线路”改造成真正有故障独立性的备份架构，并规定何时切换、谁来切、多久恢复。

## 1. 区分 7 个故障域

| 故障域 | 典型问题 | 两个方案是否可能同时失败？ |
|---|---|---|
| 接入介质 | 家庭宽带断线、Wi-Fi 路由器损坏 | 都依赖同一条宽带则会 |
| 本地运营商 | 某运营商网络异常 | 两条方案都跑在同运营商仍可能会 |
| 本地设备 | 电脑更新后网络栈异常 | 同一台设备多客户端仍会 |
| 配置/客户端 | 同一订阅配置更新出错 | 主备使用同订阅/同软件会 |
| 出口服务器 | VPS 宕机、磁盘满、带宽耗尽 | 同服务器不同端口/协议一定会 |
| 上游供应商 | 服务商机房、账户、支付、管理面故障 | 同品牌两个地区未必独立 |
| 目标服务 | 目标网站宕机、账号安全验证、地区许可限制 | 换网络不解决 |

**判断备用是否有效：**至少回答“如果主服务器完全关机，备用还能工作吗？”以及“如果家庭宽带断线，备用还能工作吗？”前者不成立，备用不具备出口独立性；后者不成立，备用不具备接入独立性。

## 2. 三套可落地架构

### 轻量版（普通用户/低频）

- **主用**：一个经过 7 天测试的合法授权服务。
- **备用**：手机蜂窝上网 + 另一条经过实际任务验证的服务（必要时）。
- **应急**：资料离线、待网络恢复时发送。
- **限制**：如果备用只是“同服务不同节点”，它只减少单节点失效，**不保证服务商级故障恢复**。

### 生产力版（开发者/创作者）

- **主用**：常用宽带上满足服务条款的受控接入。
- **备用**：不同维护方/不同供应商管理的接入，以及手机热点作为下层独立网络。
- **临时缓冲**：源代码本地提交、视频分段导出、文案草稿本地保存。
- **边界**：自建 VPS 需要更新、补丁、备份、资源告警；它不必然比可靠的商业服务稳定。

### 企业版（客户资料/跨境业务）

- 先确定组织政策、采购与数据流合规，采用可管理、可审计的服务。
- 双 WAN 或不同运营商接入；必要时跨可用区/供应商设计专线/管理式 SD-WAN，并向供应商索取明确 SLA。
- 设置运维联系人、变更冻结窗口、合规日志留存期限、分级事故通报。
- 不得把员工私人 VPN 当作生产环境的替代合规路径。

## 3. 明确切换阈值：三段状态机

以下阈值是**可调整的示例团队内部规则**，不是行业事实；根据你业务的数据修订。

| 状态 | 条件例子 | 动作 | 禁忌 |
|---|---|---|---|
| 绿色 | 核心任务正常，会议可维持 | 不动当前线路；记录一次心跳 | 因 1 次测速“更快”随意切 |
| 黄色 | 连续 2 次真实任务失败，间隔 30 秒复测 | 停止新上传，打开备用试运行 | 立即重启服务器/更新全部配置 |
| 红色 | 5 分钟关键任务未恢复，或安全策略不满足 | 切换已演练备用；关键任务必要时停止（fail closed） | 在敏感登录/交易中反复切出口 |

### 备用切换 SOP

1. 记录故障时刻、当前接入、目标任务、错误；截屏前打码。
2. 暂停上传、支付、客户操作；确认任务不会重复提交。
3. 关闭主网络代理/隧道，避免多个系统代理互相争用。
4. 启用预先验收的备用路径；在低风险目标先进行确认。
5. 仅在出口符合业务安全与条款要求时恢复关键任务。
6. 主线恢复后先在测试任务验证，不在会议/上传中途切回。
7. 记录 RTO（从故障开始到任务恢复的时间）与 Root Cause（证实/待查分开）。

## 4. 开机自动切换还是手动切换？

- **个人使用**：手动切换往往更可控，可避免意外跨地区登录、DNS 漏配与重试重复提交。先做到可观测、可回滚，再谈自动化。
- **生产系统**：自动切换必须有健康检查、抖动抑制（避免两条线来回跳）、状态监测和审计；从不以“单次 ping 成功”作为业务健康。
- **Tailscale 等组网技术**：其 subnet router/app connector 对重叠路由有故障接管能力，但与任意海外上网路径不同，不能推导所有场景自动恢复。参见 [官方 HA](https://tailscale.com/kb/1115/subnet-failover/) 和 [路由选择](https://tailscale.com/docs/features/route-selection)。

## 5. 四种必须做的演练

- **断主方案：**人工断开主连接，核对备用能否完成同一真实任务。
- **断主介质：**停止家庭 Wi-Fi，改为蜂窝热点，核对出口/设备是否符合预期。
- **客户端冲突：**退出 VPN/代理后，局域网与常用国内 App 能否恢复。
- **供应商失联：**无法登录服务商面板/不能收到邮件时，备用的配置和恢复码是否仍可取用。

填写 [主备故障矩阵](../templates/主备故障矩阵.md)。**一次演练成功不能证明未来永久可用**，每月重复关键演练，出现大版本更新后复测。
