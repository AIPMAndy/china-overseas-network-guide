# 24｜30 分钟启动：第一次正确使用，到每天稳定工作

**适合谁：**有授权网络接入方式，但不知道如何在设备上保持长期稳定的人。**最终产出：**一张网络档案、一份三任务验收记录、一个确实可用的回滚路径。时间是教学节奏，不构成性能保证。

## 先做决策：你需要哪种网络？

| 你想做的任务 | 优先思路 | 不要直接做的事 |
|---|---|---|
| 国内银行、微信、地图、工作内网 | 原网络直连，尊重单位网络要求 | 不必要地把个人敏感流量交给代理 |
| GitHub、官方文档、远程代码仓库 | 经授权的接入；验证浏览器和终端分别可用 | 只看 IP 就认为 Git/CLI 已可用 |
| AI 网页和 API 开发 | 先核对目标服务地区资格，再测试网页、CLI、API | 把可访问页面误认为有账号/API 使用资格 |
| 海外视频会议 | 优先可预测延迟、抖动、丢包；准备语音/电话备用 | 把大文件测速当会议质量 |
| 境外出差或跨境办公 | 企业批准的远程接入；漫游需核对运营商路径 | 假定“境外 eSIM = 所有 App 稳定” |
| 企业客户、生产环境、财务 | 企业批准/管理的接入和审计方案 | 个人代理处理客户机密 |

## 第 0 步（3 分钟）：安全底线

1. 明确个人/企业用途与使用权限；企业设备先看 IT 政策和采购要求（见 [18 章](18-企业接入与合规边界.md)）。
2. 从官方开发者/厂商来源安装客户端。记录发布页面和版本；不导入未知证书、不关闭证书校验。
3. 确认你有**合法且明确授权**的访问凭据；绝不把订阅、服务器私钥、面板地址提交给 GitHub 或 AI。
4. 保存现有工作网络设置截图，确认能关闭客户端、关闭系统代理、恢复原 DNS 和路由。

## 第 1 步（5 分钟）：建立网络档案

复制 [网络使用策略卡](../templates/网络使用策略卡.md)，只填写非敏感信息：主方案类型、备用方案类型、设备、用途、负责维护者、付费周期、失败时的默认行为。**不要写真实服务器公网 IP、订阅 URL、用户名、Token。**

推荐为三个场景分别建立档案：①家庭/办公室 Wi-Fi；②手机热点；③外出公共网络。每个环境单独验收，不互相推断。

## 第 2 步（7 分钟）：依次验证三件事

1. **基础联网：**在不启动额外接入时，先打开一个正常可达的网站，确保设备本身在线。
2. **实际路径：**启用已授权的方案后，只访问你有权使用的目标服务，记录页面加载是否成功。必要时核验公开 IP 与 DNS 行为，但**出口符合预期 ≠ 全流量安全 ≠ 账号地区资格**。
3. **应用级工作流：**用一个低风险真实任务做验收。例如 GitHub 读公开仓库、下载官方文档、在获授权的 API 沙盒做一次低额度请求。不要用客户生产凭据做网络测试。

验收时把“成功连接”“网页加载成功”“真正完成任务”分成三列。任一环节失败，就按 [33 章故障场景](33-十个真实可复现排障剧本.md) 处理。

## 第 3 步（5 分钟）：设定分流与异常默认行为

默认从**最小必要流量**开始；需要更多应用时再扩大范围。常见三种模式：

- **模式 A：按需使用。** 国内任务时关闭跨境接入，需要海外服务时再启动；最适合小白和低频使用。
- **模式 B：按目的地分流。** 明确的内网、本地业务直连，允许的境外业务走指定出口；一定检查 DNS、IPv6 和应用内代理行为。
- **模式 C：企业全隧道。** 按公司安全策略将网络统一经受管理的出口，适合审计需求，不应私自绕过公司安全组件。

**特别注意**：浏览器扩展代理通常不覆盖系统级应用；系统代理不一定覆盖所有 UDP 流量；TUN 会触及路由、DNS、局域网权限。切换模式前记录设置，切换后重新进行“三件事”测试。

## 第 4 步（5 分钟）：做真正的备用

关闭主方案，使用独立备用网络做同一低风险任务（不同上游或不同接入介质更有价值）。记录切换所需时间，确认旧网络设置正常恢复。**没实际演练过的备用，等于还没有备用。**

## 第 5 步（5 分钟）：制定一天的使用节奏

| 时间节点 | 动作 | 检查证据 | 失败时 |
|---|---|---|---|
| 开工前 3 分钟 | 检查网络、续费日期、目标任务 | 目标服务可完成低风险操作 | 换备用，不在登录关键账号时反复切换 |
| 开工中 | 长连接会议/上传时尽量不切换 | 会话不中断、工具无明显重试 | 停止敏感任务，优先恢复通讯 |
| 工作结束 | 退出非必要接入，关闭临时代理变量 | 国内服务与局域网恢复 | 执行回滚卡 |
| 每周 15 分钟 | 轮流测试主备，检查版本与密钥状态 | 7 天测量表、异常记录 | 暂停升级并保留已知可用配置 |
| 每月 30 分钟 | 核对账单、风险、供应商、备份 | 月度策略复盘表 | 淘汰高风险/低价值方案 |

**本章交付判断：**不是“绿色已连接”，而是能完成任务、能在失败时改用备用、能安全退回原网络。
