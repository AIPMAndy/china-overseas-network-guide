# 04｜电脑端：Mac、Windows、Linux 从安装到验收

**本章结果：**你会找到可信的客户端、选择模式、导入有权使用的连接、定位“浏览器能用，软件不行”的原因。

## 先认识两个开关

**系统代理**：让遵循系统代理设置的应用把符合条件的请求交给代理。某些游戏、终端程序、企业 App 或系统服务不一定遵循它。

**TUN/设备级 VPN**：创建虚拟网络接口，让更多流量可以经指定隧道走。需要更高系统权限，可能影响 DNS、局域网访问、企业 VPN、IPv6 与软件兼容性。**它也不能天然保证所有流量都受保护**，必须测试。

## macOS：首选清晰可回滚的方式

1. 点击苹果菜单 → **关于本机**，记下是 Apple 芯片还是 Intel、macOS 版本。
2. 如果走 [Outline](02-Outline图形化自建.md) 方案，用 [Outline 官网](https://getoutline.org/get-started/) 提供的客户端；若走 [AmneziaVPN](03-AmneziaVPN图形化自建.md)，用官方应用。不要随手在网络上安装“同名增强版”。
3. 导入你被授权使用的密钥或配置。第一次连接后，允许系统提示的网络扩展/VPN 权限前确认应用发布者。
4. 打开普通 HTTPS 站点、目标服务、终端工具，分别测试。终端的 `curl` 可能走系统代理，也可能读取 `http_proxy`/`https_proxy` 环境变量；因此要查实际进程的代理设置。
5. 退出客户端并关闭代理，确认不再残留系统代理或 DNS 修改。

**自查命令（仅查看状态，不修改系统）：**

```bash
# 检查 macOS 当前代理（接口名按自己的网络服务替换）
networksetup -listallnetworkservices
scutil --proxy

# DNS 状态摘要
scutil --dns | head -n 35

# 网卡与 IP 信息（输出可能涉及隐私，勿直接公开）
ifconfig | head -n 40
```

## Windows：明确 x64 / ARM64

1. **设置 → 系统 → 系统信息** 查看系统架构。
2. 安装官方 Windows 客户端。若使用规则类客户端，可参考 [Clash Verge Rev 官方仓库](https://github.com/clash-verge-rev/clash-verge-rev)及其 Releases；安装客户端后仍**需要自己的授权配置**，不能凭软件名称自动联网。
3. 按软件官方说明导入配置、开启系统代理并测试。只有存在应用不服从系统代理等明确需求时，再考虑以管理员权限开启 TUN，并记录原设置。
4. 关闭连接后查看“设置 → 网络和 Internet → 代理”，确认没有留下无法访问的旧代理地址。

**只读检查（PowerShell）：**

```powershell
Get-NetIPConfiguration
Get-DnsClientServerAddress
Test-NetConnection example.com -Port 443
```

## Linux：确认桌面与命令行是否走同一条路

Linux 上 GUI 代理、shell 环境变量、容器、systemd 服务可能各走各的。不要只用 Firefox 能否打开网站判断整个 Linux 主机都已经通过隧道。安装软件以维护方文档与发行版官方包管理为准。

```bash
# 不显示任何密钥，仅查看是否存在常见代理环境变量（值可能敏感）
printenv | grep -Ei '^(http|https|all|no)_proxy=' | sed -E 's/=.*/=[REDACTED]/I'

# 基础 DNS 解析与 TLS 访问测试
getent hosts example.com
curl -I --max-time 10 https://example.com
```

## 一次成功的定义

**不能只看软件界面显示“已连接”。**至少有三个凭证：目标 HTTPS 站点能加载；切换网络后重复测试；断开时系统网络能正常回退。执行完 [第 06 章](06-如何判定稳定.md) 的测量再做稳定性判断。
