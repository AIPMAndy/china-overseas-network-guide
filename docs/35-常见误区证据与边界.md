# 35｜反直觉事实与误区：稳定、速度、隐私、账号、合规

本章为读者最容易产生错误预期的 16 个问题。**事实标注以相关官方文档为边界，不声明中国大陆的当前可用率。**

1. **买 VPS 就等于稳定？** 不。服务器只解决部分控制权，网络上游、软件维护、DNS、协议、目标服务仍可能失败。
2. **同一个 VPS 搭 3 个协议等于有 3 条备用？** 不。同机故障域相同，最多提升软件/协议级多样性。
3. **手机能上网，电脑开热点也能自动经同一代理？** 不确定。热点客户机有独立网络行为，必须另测。
4. **VPN 图标显示已连接代表所有 App 都走 VPN？** 不一定。系统代理、TUN、应用自己的网络栈和 Split Tunnels 都可能影响路径。
5. **DNS 设置不对会怎样？** 域名无法解析、企业内网域名不可达、请求命中意料外路径。Cloudflare 明确区分路由分流与 DNS 配置：[官方](https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/route-traffic/split-tunnels/)。
6. **为什么同网络浏览器成功，Git、Docker 失败？** 因为每个应用/守护进程可有独立代理配置。Docker Desktop 也有不同于 Linux daemon 的设置：[官方](https://docs.docker.com/engine/daemon/proxy/)。
7. **买了“原生住宅 IP”就能通过平台国家资格？** 不能推导。IP 属性不等于真实住址、合法身份、服务条款和支付/税务资格。
8. **把 Mac 时间改为美国时间就“算美国设备”？** 不成立。时间、网络、支付和真实身份是不同维度，虚假信息可能违反规则。
9. **Tor 一定更快、更匿名？** 不。Tor 有明确隐私模型和局限，其网桥主要解决可连接性，并非万能速度/匿名保证：[官方](https://support.torproject.org/tor-browser/circumvention/using-bridges/)。
10. **Cloudflare WARP 能随便选国家？** 它是特定网络/隐私工具，不能按个人想象充当国家身份服务：[官方模式](https://developers.cloudflare.com/warp-client/warp-modes/)。
11. **Tailscale 连接就等于具备海外公共出口？** 不。设备互联和经 exit node 转发公网流量是不同功能，后者需要明确配置并获得权限：[官方](https://tailscale.com/docs/features/exit-nodes)。
12. **eSIM 等于海外网络？** 不确定。设备兼容、运营商合同、数据漫游与出口落地均需分别核验。
13. **关闭证书验证可以解决不能访问吗？** 危险。它可能掩盖中间人或错配，正确方法是检查证书链、时间和受信任网络设置。
14. **升级到最新版永远最稳定？** 不一定。正确方法是测试环境先验收、保留可回滚配置、在合适窗口升级。
15. **只关注延迟就够了？** 不够。完成真实任务的成功率、p95、故障恢复与账号异常更贴近业务价值。
16. **这份教程能保证在中国合法且稳定使用一切海外服务？** 不。适用法律、个人/企业目的、服务条款、具体网络和时段都要独立判断。教程提供选择与核验方法，不提供法律结论或现实线路性能承诺。

**贯穿原则：**官方文档证明产品设计，复现实测证明特定条件下的表现；匿名营销帖与一次测速都不足以证明普遍稳定。要贡献真实案例，使用 [来源登记](../templates/来源可信度登记表.csv) 并删去敏感信息。
