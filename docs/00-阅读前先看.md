# 00｜先读：法律边界、真实需求与威胁模型

**本章结果：**你知道“需要访问外部网站”和“有权配置何种跨境联网方案”是两件事，能辨别常见的高风险操作。

## 1. 先确定你的使用场景

将需求写成一句话，例如：“我需要在自己的电脑上访问某海外学术网站/代码托管平台，传输的是公开资料，不包含客户隐私。”如果涉及公司账号、源代码、财务、个人信息，先问信息安全负责人：是否有经过审批的专线、零信任网关、企业 VPN、海外云桌面或其他合规途径？组织网络政策可能比个人使用的技术选择更严格。

**法规事实（请阅读原文）：**《中华人民共和国计算机信息网络国际联网管理暂行规定》第六条对国际出入口信道作出规定；工信部 2017 年的通知明确约束未经批准开展跨境 VPN 等经营活动。不能由某篇文章推导出“所有个人使用都合法”或“所有个人使用都违法”的一刀切结论。法律适用取决于行为、地区、主体、用途和当下监管实践；有商业计划时应获得专业法律意见。

- [工信部：国际联网管理暂行规定](https://hbca.miit.gov.cn/xxgk/zcwj/flfg/art/2020/art_b118b9e4e97d4a8e9e6af358c78ac4dc.html)
- [工信部：清理规范互联网网络接入服务市场通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2017/art_a940645e940946e1a62cd6c90a4e994e.html)

## 2. 这个指南不做的事

不售卖节点、订阅、VPS；不提供他人的登录凭据；不兜售“零风险”网络；不教非法经营或规避组织安全监管。示例 IP 统一用文档保留段 `203.0.113.0/24`，示例密钥用 `REPLACE_ME`。不要把本教程里的占位符当作真的可用服务器。

## 3. 五类威胁，逐一评估

| 风险 | 常见现象 | 你该做什么 |
|---|---|---|
| 安装包供应链 | 搜索引擎广告页/群聊发来的改版客户端 | 下载页追溯官方项目，校验签名或 SHA256；拒绝要求关闭安全软件的未知程序 |
| 出口服务提供方 | 服务商能看到连接元数据，甚至非加密流量 | 使用 HTTPS，减少敏感活动，不轻信“零日志”的未经审计营销 |
| 网络位置暴露 | DNS、IPv6、WebRTC 或应用绕开代理 | 分别检查代理模式；必要时按官方说明启用全局路由，验证回退能力 |
| 账号风控 | 频繁改变地区、共享出口、登录异常 | 使用长期一致的合规网络和账号安全设置，遵守平台条款，不保证不触发风控 |
| 凭据泄露 | GitHub Issue、截图、终端录屏暴露密钥 | 每个设备单独授权，发现泄露立即撤销并重新签发 |

## 4. 开始前确认

- [ ] 先确认网络用途和适用的法规、企业网络政策。
- [ ] 明确要连接的设备与系统：Mac Intel/M 芯片、Windows x64/ARM、iOS、Android。
- [ ] 明确可接受的费用和恢复时间。
- [ ] 备份当前网络设置；知道如何关闭连接和卸载客户端。
- [ ] 不在公共仓库或聊天记录里发布真实 IP、SSH 密码、私钥或订阅 URL。

**完成凭证：**在自己的私有记录里写下用途、设备、负责人（如适用）和可接受的停机时间。过不了这个检查，先暂停部署。
