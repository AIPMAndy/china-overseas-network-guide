# 33｜10 个可复现故障剧本：看到现象，就照表处理

**证据说明：**以下是根据网络层次和官方文档构造的**操作演练场景**，不冒充已验证的个人故事、客户案例或中国大陆现场实测。实际原因需要经过对照实验确认。优先做无破坏诊断，涉及单位设备由 IT 协助。

## 01｜所有应用都没有网络

**先看：**关闭额外接入后正常网络是否通。若也不通，优先检查 Wi-Fi、网线、蜂窝信号、网关/欠费，而不是先重装 VPN。若普通网络恢复，但授权连接不能用，再看客户端状态。**禁止：**反复重置设备、同时变更 DNS 和网络路由。

## 02｜只有浏览器能打开公开代码仓库，终端失败

**初步假设：**浏览器用了扩展/系统代理，终端没有继承正确设置。**步骤：**(1) 用公开目标 `curl -I`；(2) 仅检查环境变量名是否存在；(3) 仅使用经过验证的本地代理做临时对照；(4) 确认公司策略。详细见 [26 章](26-Mac-Windows-终端-IDE-Docker.md)。**验收：**同个目标在浏览器和 CLI 均成功。**回滚：**撤销临时 shell 配置。

## 03｜终端 curl 能用，Docker pull 失败

**初步假设：**Docker daemon 或 Desktop 的网络设置独立。**步骤：**确认 Desktop 或 Linux Engine；查看 Docker 官方代理文档；核对镜像源访问权限；不使用来历不明的镜像加速站。**验收：**受控环境拉取公开小镜像。**回滚：**恢复原有 daemon/Desktop 设置。来源：[Docker 官方](https://docs.docker.com/engine/daemon/proxy/)。

## 04｜打开海外网页正常，手机热点的 Mac 失败

**初步假设：**手机本机 VPN 并不自动覆盖热点客户机。**步骤：**Mac 独立验证当前出口/路由和真实目标；确保 Mac 的已授权访问配置独立有效。**验收：**Mac 真实业务成功，不拿手机的截图代替。**回滚：**关闭 Mac 临时代理，恢复原正常网络。

## 05｜设备“已连接”，网页依然打不开

**可能位置：**目标站不可用/账户限制、DNS、路由、TLS、协议与应用区别。**步骤：**先比较已知正常公开 HTTPS 页面和目标页面；做 DNS 与 HTTPS 阶段区分；查看软件本地诊断并脱敏。**禁止：**关 TLS 证书校验、跳过证书错误。**验收：**完成业务任务，不仅是状态灯变绿。

## 06｜晚上不稳定，白天正常

**可能原因（未证实）：**本地接入拥塞、上游容量、目标服务峰值、协议特性。**步骤：**固定同一设备、同一公开任务与相同测试流程，每天三时段持续一周；跨 Wi-Fi/蜂窝与备用上游对比。**验收：**有分组结果和明确样本量。**禁止：**凭一次晚间卡顿推定具体封锁原因。

## 07｜切到 TUN 后 NAS/打印机连不上

**可能原因：**本地路由、局域网权限、名称解析与网段冲突。**步骤：**保存现状后暂时撤销新 TUN 设置，对比同一局域网服务；检查 LAN 访问与单位政策。**验收：**恢复 NAS 且其他关键任务正常。**禁止：**打开不必要的所有内网访问权限。

## 08｜海外服务提示地区限制或账号异常

**判断：**IP 位置只是可能相关因素之一，账号资格、支付主体、手机号、税务或服务条款另有规则。**步骤：**检查官方服务地区与账户资格要求、查看官方安全通知、使用平台支持的验证/恢复入口。**禁止：**伪造住所/证件或反复切换可疑出口规避安全机制。**验收：**账户被正式允许访问，而非仅暂时打开页面。

## 09｜服务器在线，连接突然失败

**初步假设：**服务器服务进程、证书/凭据过期、配置更改、安全组、账单、系统资源、上游异常。**步骤：**先看授权管理面板/云厂商官方状态；只读检查资源、上次变更及期限；如需运维修复，先备份再操作。**禁止：**把 SSH 密钥、IP、配置截图公开求助。**验收：**客户端实测任务完成，恢复后记录故障原因或标注“未知”。

## 10｜两条“备用”一起失效

**根因排查：**是否同一 Wi-Fi、同 VPS、同服务商控制面、同份配置、同信用卡支付、同一台设备？**步骤：**逐层画故障域；切换真正独立下层接入；用离线工作流保住数据和交付。**验收：**实测至少一种备用在主方案彻底关停时仍能工作。详见 [28 章](28-主备线路与故障独立性.md)。

## 每次故障都填写“最短复盘”

`症状—开始时间—影响任务—试过的唯一变量—证据（已打码）—临时解决—根因（确认/待定）—永久修复—回归测试—责任人`。

能复现并排除问题的记录才可以贡献为“真实案例”；未经证实的场景不能写“已解决 XX 运营商封锁”。
