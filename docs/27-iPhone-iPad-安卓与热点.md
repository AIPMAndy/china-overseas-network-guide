# 27｜移动端全场景：iPhone / iPad / Android / 热点 / 漫游

本章不承诺某个 App 在中国大陆永久可达。**手机、平板、电脑之间，不要把“安装同一个 App”视为等价网络行为。**

## 一、每台设备都做四组测试

| 测试条件 | 怎么操作 | 要记录什么 | 常见失败 |
|---|---|---|---|
| A 家中 Wi-Fi | 连 Wi-Fi，按需启动合法接入 | 目标任务、DNS、出口、状态 | 路由器和本机 DNS 不一致 |
| B 蜂窝移动网络 | 关闭 Wi-Fi 单独测试 | 任务成功与延迟、流量消耗 | 某个协议/接入受限 |
| C Wi-Fi → 蜂窝 | 先做低风险任务，切换网络后重试 | 重连耗时、登录会话 | 网络切换导致连接失效 |
| D 热点共享 | 用手机热点连接 Mac/iPad，单独检查 Mac/iPad 出口 | 电脑的出口与 App 成功率 | 以为手机 VPN 会自动保护热点客户机 |

**关键知识：**热点共享出去的设备，其网络路由与手机本机 VPN 不一定相同。不要假定“手机绿色已连接 → Mac 自动经过同一出口”；必须在 Mac 自己检测并配置所需的合法网络路径。

## 二、Apple 设备：按需连接和企业管理的差别

[Apple 官方的 VPN deployment](https://support.apple.com/guide/deployment/vpn-overview-depae3d361d0/1/web/1.0) 提到 VPN On Demand 和 Per-App VPN，但后者常涉及 MDM、受管理配置和应用授权；**普通用户看到一个 VPN 开关，并不代表具备所有企业级按应用路由功能。**

1. 从官方渠道安装有维护记录的 App；阅读 VPN 添加配置权限提示。
2. 先检查是否存在老 VPN 或设备管理描述文件：删除前辨明是否属于学校/公司的托管配置。
3. 在 Wi-Fi 与蜂窝下分别用低风险任务测试；锁屏一段时间后再次执行任务。
4. 若需要自动连接，优先使用厂商官方明确支持的设置，不导入陌生描述文件。
5. 用户想访问局域网设备时，检查本地网络权限与官方“允许局域网”选项；切换后测试打印机和 NAS。
6. 关闭接入时，确认国内支付、通话、地图和单位内网可恢复。

## 三、eSIM 和海外漫游：分开验证三件事

- **机型兼容：**设备实际型号、运营商锁定、iOS/Android 版本、eSIM 管理能力。中国大陆购买的设备不能一概按海外机型说明操作。见 [Apple 中国大陆 eSIM 官方说明](https://support.apple.com/zh-cn/123879)。
- **漫游机制：**境外运营商套餐是否允许在当前地区使用、数据出口落地何处、需要哪些 APN/漫游设置，以运营商条款为准。
- **账单风险：**漫游套餐的流量单位、限速、公平使用政策、热点共享限制和到期规则。先进行低量验证，再开始大流量上传。

跨境漫游的用户不应假定自己自动拥有海外账号、收款或内容创作者资格；平台规则与网络出口不同。

## 四、Android 需要额外检查

- 手机系统是否限制后台运行/电池优化导致连接被回收；各品牌菜单不同，不建议一概永久取消所有安全限制。
- 同时存在企业工作资料与个人资料时，先尊重工作资料的管理员设置。
- 若 App 提供“始终开启 VPN”和“阻止无 VPN 连接”之类安全行为，弄清它们是否会影响通话、支付、消息推送和应急功能，再决定是否启用。
- 与 iPad 一样，切换 Wi-Fi/蜂窝或热点后必须重新验证目标任务。

## 五、外出工作的三项备份

1. 本地保存工作所需文件、脚本帮助文档、客户会议号码和预约信息（不得留下明文 API 密钥）。
2. 提前准备经验证的第二网络介质，例如蜂窝/宽带的独立组合；不可用时停止敏感任务。
3. 保存 [十分钟应急处置卡](../templates/应急十分钟处置卡.md)，避免在赶会议时现场下载陌生软件。

**完成标准：**Wi-Fi、蜂窝、切换、热点这四类至少完成适用的测试；iPhone 与 iPad 分别验收，绝不靠主观感觉。
