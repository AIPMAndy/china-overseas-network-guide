# 12｜进阶：理解 Clash Verge Rev、sing-box、规则与 TUN

**本章结果：**认识高级客户端的边界，避免“全局”和“规则模式”乱切造成信息泄露或工作中断。

## 工具不是服务商

- **[Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)**：Windows/macOS/Linux 图形客户端，基于 Mihomo（Clash Meta）生态，软件本身**不包含可用节点**。安装包以官方 GitHub Releases 为准，核对最新发行版兼容性。
- **[sing-box](https://sing-box.sagernet.org/)**：跨平台网络代理工具与配置生态，官方文档持续更新。**其 iOS App Store 上架状态可能变化**，应以 Apple 平台官方文档实时信息为准。
- **[Hiddify App](https://github.com/hiddify/hiddify-app)**：开源多平台客户端，使用前核对支持格式、发布者及对应系统发行包。
- **Outline / AmneziaVPN**：提供官方图形化管理和客户端体验，配置格式不完全相同，不可随意互换。

## 有授权配置时，最小安全上手步骤

1. 从项目维护者的 GitHub Releases 取得**正式稳定版**，核对系统架构，必要时校验官方发布的 SHA256。
2. 导入你有权使用、来源明确的配置（可能是本地文件或一次性授权链接）。**未知远程订阅可能变化，内容不能默认可信。**
3. 先用软件的“系统代理 + 明确规则”测试一个低风险 HTTPS 页面；不要在不理解权限时直接开启所有增强模式。
4. 打开规则、DNS、IPv6 页面，检查“直连/代理/阻断”的策略是否匹配工作要求；不同软件的按钮名称和格式会更新。
5. 只有在需要覆盖更多应用流量、且理解本地网络受影响范围时，才启用 TUN；测试微信/本地打印机/企业 VPN/局域网资源等是否异常。
6. 保存设置快照，在故障时一键恢复到原先能工作的配置。

## 规则模式的四个典型坑

| 现象 | 为什么 | 如何核查 |
|---|---|---|
| 浏览器能访问，CLI 不行 | CLI 未使用系统代理或受不同 DNS 规则影响 | 检查终端变量、应用内代理设置 |
| 国内网站也变慢 | 被错误路由到远端 | 看命中规则日志（脱敏），调整受控策略 |
| 手机 App 提示地区/登录异常 | IP 与历史账号、设备其他信号不一致 | 遵守平台使用条款，恢复长期一致的网络 |
| 打印机/本地 NAS 不通 | TUN、路由或 DNS 影响局域网 | 检查本地网段策略及回退状态 |

## 不建议做的事

不下载所谓“绿色破解版”、不运行无人审查的远程配置脚本、不安装自签未知证书、不按陌生教程永久关闭杀毒或系统安全功能。**客户端越复杂，排障面越广**；如果已有更简单的受支持方案可以满足需求，就不必堆协议。
