# 05｜手机与平板：iPhone、iPad、Android

**本章结果：**不同设备有各自的授权配置，能解释 Wi‑Fi 正常但蜂窝流量失败的情况。

## iPhone / iPad

1. **设置 → 通用 → 关于本机**，确认 iOS/iPadOS 版本。应用商店可用性可能受 Apple ID 地区、操作系统版本及应用审核政策影响。
2. 从 [Outline 官方下载说明](https://developer.getoutline.org/zh-CN/download-links/)获取 Outline Client，或从 [Amnezia 官方支持文档](https://docs.amnezia.org/documentation/alternative-clients/)找到 AmneziaVPN/AmneziaWG 的合法应用来源。不同应用支持的配置格式不同。
3. 在应用中导入**专为这台设备**生成的授权连接。系统弹出“允许添加 VPN 配置”时，确认发布者与用途，然后按自身安全政策决定是否允许。
4. 分别在家庭 Wi‑Fi、蜂窝移动网络、手机热点下测试目标 HTTPS 服务，记下可用/不可用状态；如果出于隐私原因不适合测试某些敏感服务，就只用自己有权访问的测试站点。
5. 测试离开 VPN/应用后，是否能恢复普通网络；若与企业 MDM、工作 VPN 冲突，应优先遵循公司管理要求。

**遇到“当前地区无法下载”？**查看官方提供的其他合法渠道。不要为了这一步让陌生人远程登录 Apple ID、索取验证码，或诱导你安装未知描述文件/企业证书。

## Android

1. **设置 → 关于手机**，查看 Android 版本与 CPU 架构。
2. 尽量通过官方应用商店或开发者维护的 GitHub Releases 下载；核对项目所有者、签名/哈希以及是否为稳定版。
3. 导入自己的授权连接；授予 VPN 权限前确认开发者与安装包来源。
4. 在不同网络（Wi‑Fi/5G/热点）做相同验收；注意部分手机的省电策略可能关闭后台进程，查官方电池优化指引。
5. 若设备支持“始终开启 VPN”“无 VPN 时阻止连接”，理解这些选项会影响离线和局域网服务。先确保有应急回退方法。

## 三个典型问题

**1. Wi‑Fi 可以，5G 不行。**先关掉 Wi‑Fi 只测 5G，再换热点对照。可能是运营商、IPv4/IPv6、UDP 路径或本机 VPN 权限问题；不能仅凭一项测试断定原因。

**2. 微信/银行 App 出现异常。**暂时退出 VPN，在符合平台和公司要求的网络下使用，再逐项排查分流规则。不要为尝试访问外站而改变支付及实名身份信息。

**3. 手机能访问，电脑不能。**比对的是同一**有效密钥及同一服务端**吗？有些配置绑定设备或限制连接数；检查电脑应用、系统代理、网络权限，而非首先重装服务器。
