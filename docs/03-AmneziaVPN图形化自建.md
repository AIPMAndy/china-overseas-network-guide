# 03｜AmneziaVPN：不用背命令，也能理解自建流程

**适用条件**：受监管规则/服务条款允许；你有能正常 SSH 访问的自有 Linux VPS。主线参考 [Amnezia 官方 Self-hosted 教程](https://docs.amnezia.org/documentation/instructions/install-vpn-on-server/)。实际连接表现因地区、运营商、服务器和时间而异，不承诺在中国大陆持续可用。

## 1. 准备与安装

1. 在自己的电脑上从 Amnezia 官方网站/仓库取得 **AmneziaVPN** 客户端（核对项目发布者，不安装随机 APK）。
2. 先核查 [VPS 官方要求](https://docs.amnezia.org/)、SSH 账号权限、云防火墙和实例救援能力。部署前做可恢复备份。
3. 打开客户端，点击 **+** 或 **Get Started**，选择 **Self-hosted VPN**。
4. 输入自己 VPS 的公网 IP、SSH 端口（默认不一定是 22）、SSH 用户名以及本地持有的密钥/密码。**这些凭据仅输入你确认来源可靠的本地官方客户端；不要粘给教程作者。**
5. 选择 Automatic（当前官方文档介绍为安装 AmneziaWG）或者在 Manual 中自行选择支持的协议。按客户端界面安装，留意服务端运行状态、端口及协议类型。
6. 部署后通过客户端开启连接；打开日常需要的网站/API，记录实测结果。

> 官方教程指出安装过程中可能用到随机 UDP 端口，并建议根据网络环境调整；**不能把“换某个神奇端口”理解成保证有效**。改端口前先确认云防火墙、服务器防火墙、其他服务和当地合规边界。见 [官方部署文档](https://docs.amnezia.org/documentation/instructions/install-vpn-on-server/)。

## 2. 添加第二台设备

不要把“管理者全权限”凭据发给其他设备或任何陌生人。使用 Amnezia 的 **Share → Guest access**，选协议和设备，生成单独的访问配置。对于官方 AmneziaWG 客户端，官方说明应导出对应的 **AmneziaWG native format `.conf`**；不要把 `vpn://` 连接密钥与 `.conf` 混为一谈。详见 [官方分享文档](https://docs.amnezia.org/documentation/instructions/amnezia-hosting-sharing/)。

逐台导入并连接；**避免多设备复用单个原生配置文件**。设备失去控制时，通过客户端的用户管理界面撤销对应授权并重新生成。

## 3. 用一分钟做验收

- [ ] 客户端连接能建立。
- [ ] 一般 HTTPS 网站可打开，目标工作网站/API 真实可用。
- [ ] 改用手机热点后，知道是否仍可工作。
- [ ] 关闭连接以后本机能恢复正常上网。
- [ ] 第二设备有独立的访问配置；管理权限没有流出。

## 4. 失败后怎么修

**SSH 连接失败**：服务器是否运行 → 登录账号和 SSH 端口是否正确 → 云厂商防火墙 → 本地网络是否能访问 SSH。不要盲目暴露 SSH 到全网。

**安装失败**：按官方支持的 Linux/软件要求核对；检查磁盘、Docker/内核相关依赖、时间、系统更新、端口占用，并只在有快照时重试。

**连得上但无法使用**：先用 [第 07 章排障树](07-故障排查树.md) 分离本地 DNS、目标网站、VPN 协议、服务器出口问题。不要因为一个网站失败就删除整个系统。

**安全原则**：任何“一键脚本”都应在读懂来源、权限及回滚方式后运行。业务服务器与个人实验服务器尽量分开。
