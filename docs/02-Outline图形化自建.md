# 02｜Outline：用官方 Manager 自建，按步骤验收

**适用条件：**你已确认法律/合同允许；有一台自己管理的空白 Linux VPS，且具备 SSH/云控制台恢复能力。下列步骤基于 [Outline 官方部署文档](https://developer.getoutline.org/zh-CN/vpn/getting-started/server-setup-manager/)，不同版本界面可能变化。

## 你需要准备什么

- 一台受控 Linux VPS（系统版本和 CPU 架构以 Outline 官方当前要求为准）；公网连接，云控制台救援入口。
- 管理电脑（Windows/macOS/Linux）；从 [getoutline.org](https://getoutline.org/get-started/) 取得 **Outline Manager**。
- 实际使用设备；从官方地址取得 **Outline Client**。注意：Manager 管理服务器，Client 连接服务器。
- 独立的 SSH 凭据。建议使用 SSH 密钥及云平台多因素认证；**不要把凭据发送到公开聊天机器人、论坛或 Issue**。

## 手把手部署

### 第 1 步：确认服务器“干净”

在云厂商面板里保存当前系统、端口、账单信息；如果已有网站、数据库或代理服务，先做快照并检查冲突。确认云防火墙的 SSH 入口仅对可信管理地址开放（若网络条件允许），不要为省事直接永久开放所有端口。对服务器 SSH 端口、磁盘空间、时间同步做最小检查。

**完成凭证**：控制台可以看到运行状态；你能使用 SSH 登录；知道如何重置实例。

### 第 2 步：在管理电脑安装官方 Manager

前往 `https://getoutline.org/`，识别 Manager 和 Client 的不同。安装管理器，打开后点击 **+**。自己有 VPS 时选择 **Set up Outline anywhere / 随时随地安装 Outline**。需要在 VPS 执行的命令以**此刻官方管理器所显示的命令**为准；先检查命令会做什么，再通过 SSH 在受控机器操作。不要复制博客里的过期脚本或随机“一键脚本”。

**可能失败**：系统不支持、Docker 拉取失败、DNS 不可用、云防火墙阻断管理端口、残留服务占用端口。此时先查官方错误提示，别重复重装十次。

### 第 3 步：创建服务器和第一把密钥

Manager 显示服务端建立成功后，打开服务器详情；点击 **+** 创建一把 **仅用于你的一台设备**的访问密钥，按设备命名，例如 `my-mac`。正式密钥可能是包含服务器地址的 URI，**不要贴到 GitHub**。可以按 Manager 功能设置适当流量上限。

**完成凭证**：Manager 显示服务器健康状态（如有）及你创建的访问密钥，且你已安全保存管理入口。

### 第 4 步：装 Client，导入密钥

从 [Outline 官方客户端](https://getoutline.org/get-started/) 下载适合设备的版本。打开 Outline Client → 添加连接/粘贴访问密钥 → 保存 → 连接。iOS 及 Android 应以官方应用商店或 Outline 官方备用下载页面为准。遇到 App Store 地区限制，先查官方支持渠道，不建议越狱或安装可疑企业签名包。

**完成凭证**：目标网站实际能加载、HTTPS 证书正常，并在不同网络下重复测试。

### 第 5 步：做撤销演练

新建一把演示密钥，在测试设备导入并确认成功。回到 Manager 删除这把演示密钥，验证它无法再连接。**主用密钥不要在演练时误删。**这一步证明你有退出和密钥轮换能力。

## 常见卡点

| 现象 | 最先检查 | 不应该做 |
|---|---|---|
| Manager 连不到服务器 | SSH、公网地址、云防火墙、系统支持 | 反复重装而不读错误 |
| Manager 成功，Client 没网 | 密钥是否对应当前服务器，实际服务端防火墙/路由 | 把访问密钥贴论坛求助 |
| 一台设备能用，另一台不能 | 单设备网络、App 权限、不同密钥 | 立刻断言服务器坏了 |
| 连接成功但目标网站打不开 | HTTPS 目标可达、DNS、分流和本地网络 | 为了“修复”关掉 TLS 证书验证 |

## 安全与结束检查

- [ ] 每台设备一个独立密钥，方便撤销；退出设备后删除对应密钥。
- [ ] 不把完整的 Manager 管理链接、SSH 私钥、Client 密钥放公共地方。
- [ ] 持续关注 [Outline 官方文档](https://developer.getoutline.org/vpn/getting-started/share-access/)；保持服务端和客户端更新。
- [ ] 自建只验证了“当前可用”；还没通过 [七天验收](10-七天验收计划.md)，不能称“稳定”。
